청약 용어 사전 — 자주 나오는 용어 30개를 쉬운 말로 정리

2026-09-30 · aptpass 편집팀

청약 공고문은 용어가 어려워 처음 읽을 때 막히기 쉽습니다. 자주 나오는 용어를 분류별로 정리했습니다. 관련 가이드가 있으면 링크를 함께 적었습니다.

통장·자격 용어

  • 청약통장(주택청약종합저축): 청약 자격을 얻기 위한 통장 → 통장 종류
  • 1순위·2순위: 통장 조건에 따라 나뉘는 청약 자격 순위 → 1순위 조건
  • 무주택 세대구성원: 세대 전원이 주택을 소유하지 않은 상태 → 무주택 기준
  • 세대주: 주민등록상 세대의 대표자
  • 가점제·추첨제: 점수 순 또는 추첨으로 선정하는 방식 → 가점 계산법
  • 해당지역·기타지역: 단지 소재지 거주 여부에 따른 구분 → 거주지 요건

공급 유형 용어

  • 일반공급·특별공급: 일반 경쟁과 별도 물량 배정 → 특별공급
  • 공공분양·민간분양(민영주택): 공급 주체 구분 → 공공·민간 비교
  • 무순위(잔여세대) 청약: 계약되지 않은 물량 재공급 → 무순위 청약
  • 예비 당첨자: 계약 포기 시 대신 기회를 얻는 순번자 → 예비 당첨자
  • 선분양·후분양: 짓기 전/후 분양 → 선·후분양

규제·제한 용어

  • 투기과열지구·조정대상지역: 규제 지역 유형 → 규제지역
  • 재당첨 제한: 당첨 후 일정 기간 다시 당첨될 수 없는 제한 → 재당첨 제한
  • 전매제한: 분양권을 팔 수 없는 기간 → 전매제한
  • 실거주 의무: 일정 기간 직접 거주해야 하는 의무
  • 분양가상한제: 분양가를 제한하는 제도 → 분양가상한제
  • 부적격: 자격 미달로 당첨이 취소되는 것 → 부적격 사유

면적 용어

  • 전용면적: 세대 내부 실사용 면적
  • 공급면적: 전용 + 주거공용면적
  • 계약면적: 공급 + 기타공용면적 → 면적 차이

대금·금융 용어

  • 계약금·중도금·잔금: 분양 대금의 납부 단계 → 계약 이후 절차
  • 중도금대출: 중도금을 은행에서 빌리는 대출 → 분양 대출
  • LTV·DSR: 담보 대비 대출 비율, 소득 대비 원리금 상환 비율
  • 이자후불제: 중도금 이자를 입주 시점에 내는 방식
  • 취득세: 소유권 취득 시 내는 지방세 → 취득세

기타 용어

  • 모집공고문: 청약 조건을 담은 공식 문서 → 공고문 읽는 법
  • 모델하우스(견본주택): 분양 홍보용 전시 공간 → 모델하우스 체크리스트
  • 사전점검: 입주 전 하자를 확인하는 방문
  • 분양 보증: 사업 주체가 부도나도 납부금을 보호하는 보증
  • 옵션: 발코니 확장, 시스템 에어컨 등 유상 선택 항목 → 옵션 비용
  • 입주 지정 기간: 잔금을 치르고 입주해야 하는 기간

마무리
