청약은 **공고가 나온 뒤 며칠** 사이에 결정해야 하는 경우가 많습니다. 평소에 정보와 서류를 준비해 둔 사람이 기회를 잡기 쉽습니다. 일상에서 쉽게 따라 할 수 있는 루틴을 정리합니다.

## 1. 알림 설정

- **청약홈 알림 서비스**와 관심 지역 공고 알림을 설정합니다.
- 건설사·시행사의 공식 채널은 공고 전 사전 안내를 올리는 경우가 있어 구독해 둘 만합니다.
- 알림은 **공식 채널**에서만 설정하세요([분양 사기 주의](/blog/housing-scam-warning.html)).

## 2. 캘린더 관리

- 관심 단지의 **모집공고일, 특별공급, 1순위, 당첨자 발표일**을 등록합니다([일정 읽기](/blog/how-to-read-cheongyak-schedule.html)).
- 접수 하루 전과 당일 아침에 알림을 겁니다.

## 3. 주간 점검 (10분)

| 요일 | 할 일 |
|---|---|
| 월 | 새 공고와 일정 확인 |
| 수 | 관심 지역 시세·실거래 기록([실거래가](/blog/real-transaction-price-lookup.html)) |
| 금 | 청약통장 납입 확인([납입 관리](/blog/account-payment-management.html)) |

## 4. 월간 점검 (30분)

1. 내 **점수와 자격**(통장 기간, 무주택 상태, 세대 구성)이 바뀌었는지 확인합니다([가점 계산](/blog/cheongyak-score-calculation.html)).
2. 자금 계획표를 갱신합니다([자금 계획표](/blog/down-payment-planning.html)).
3. 대출 한도와 금리 변화를 확인합니다([대출 사전 상담](/blog/mortgage-preconsultation.html)).

## 5. 관심 단지 기록표

| 항목 | 기록 |
|---|---|
| 단지명, 위치 | |
| 공급 유형·세대수 | |
| 분양가·평당 가격 | |
| 일정 | |
| 장단점·메모 | |

기록하면 비교가 쉬워지고 감정에 휘둘리지 않습니다([분양가 비교](/blog/compare-price-with-market.html)).

## 6. 서류 미리 준비

- 주민등록등본, 가족관계증명서, 소득 증빙은 **유효기간**이 있으니 접수 직전에 발급하되 **발급 방법**은 미리 숙지합니다([필요 서류](/blog/required-documents.html)).
- 본인인증 수단(공동인증서, 간편인증)을 점검합니다.

## 7. 정보 필터링

- 기사나 커뮤니티의 주장은 **공고문과 공식 통계**로 재확인합니다([뉴스 읽기](/blog/reading-subscription-news.html)).
- 과열 분위기에 휩쓸리지 않도록 자금 한도를 정해 둡니다.

## 마무리

청약은 꾸준함의 게임입니다. 하루 10분 루틴이 큰 차이를 만듭니다.
